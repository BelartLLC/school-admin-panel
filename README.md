Современная админ панель для управления школой беспилотных летательных аппаратов (БПЛА), созданная с использованием новейших технологий веб-разработки.

## ✨ Возможности

### 📚 Управление курсами
- **Создание курсов** - Интуитивный интерфейс для создания новых курсов БПЛА
- **Управление курсами** - Полный контроль над существующими курсами
- **Архив курсов** - Организованное хранение завершенных курсов
- **Категории курсов** - Гибкая система категоризации

### 🎓 Система уроков
- **Создание уроков** - Мощный HTML редактор по спецификации Emdesell
- **Файловый менеджер** - Удобная загрузка и управление медиа-файлами
- **Интерактивный контент** - Поддержка мультимедийных материалов

### 🛒 Управление заказами
- **Обработка заказов** - Комплексная система управления заказами
- **Платежная система** - Интеграция с платежными сервисами
- **Аналитика продаж** - Детальная отчетность по продажам

### 🎨 Дизайн и UX
- **Современный интерфейс** - Минималистичный и функциональный дизайн
- **Полный сайдбар** - Удобная навигация по всем разделам
- **Адаптивность** - Отлично работает на всех устройствах
- **Темная/светлая тема** - Поддержка переключения тем

## 📦 Установка и запуск

### Предварительные требования
- Node.js (версия 18 или выше)
- Bun (рекомендуется)

### Установка зависимостей
```bash
# Клонирование репозитория
git clone https://github.com/your-username/school-admin-panel.git
cd school-admin-panel

# Установка зависимостей
bun install
```

### Запуск в режиме разработки
```bash
bun run dev
```

### Сборка для продакшена
```bash
bun run build
```

### Предварительный просмотр сборки
```bash
bun run preview
```

## 🛠️ Доступные скрипты

- `bun run dev` - Запуск сервера разработки
- `bun run build` - Сборка проекта для продакшена
- `bun run lint` - Проверка кода с помощью Biome и TypeScript
- `bun run format` - Форматирование кода с помощью Biome
- `bun run preview` - Предварительный просмотр продакшн сборки
